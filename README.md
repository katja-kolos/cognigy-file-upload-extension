# Upload to ServiceNow File Storage

[Cognigy Extension](https://docs.cognigy.com/ai/for-developers/extensions) that supports uploads from Microsoft Teams to Service Now.
Supported are:
- paperclip uploads
- inline image uploads
- uploads of multiple files

A name is generated automatically for screenshots uploaded inline based on the current datetime.

This is an unofficial extension. See official extensions on [Cognigy Marketplace of Extensions](https://github.com/Cognigy/Extensions/tree/master/extensions).
